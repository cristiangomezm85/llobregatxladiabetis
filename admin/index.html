Configuración local / Netlify / Git

Local

npm run dev
# abrir http://localhost:8888/admin/

En local, el admin escribe directamente en herois.json, pobles.json, patrocinadors.json y en las carpetas de imágenes.

Producción Netlify + GitHub

CONTENT_BACKEND=github
GITHUB_REPO=usuario/repositorio
GITHUB_BRANCH=main
GITHUB_TOKEN=...
ADMIN_TOKEN=...

En producción, el mismo admin puede crear commits en GitHub y Netlify redeployará la web.
